# ASID · Gestão de demandas

Plataforma de gestão e acompanhamento de demandas da Assessoria de Inovação (ASID) da SCPMA.

- **Acesso:** mesmo usuário e senha do Hub SCPMA, restrito aos integrantes cadastrados na tabela `asid_membros`.
- **Dados:** Supabase do Hub (projeto Agenda SCPMA), tabelas `asid_membros` e `asid_docs`, com permissões por integrante e por administrador.
- **Integrações com o Hub:** perfis (foto, cargo e contato) e férias (eventos da categoria "ferias").
- **Publicação:** GitHub Pages, a partir da branch `main`, na raiz do repositório.

O sistema inteiro está no arquivo `index.html`.
